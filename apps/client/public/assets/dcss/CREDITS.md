# Dungeon Crawl 32×32 tiles (CC0)

Monstros, baús, portais e chão vêm do pack **Dungeon Crawl Stone Soup Full** (rltiles + equipe do
Dungeon Crawl Stone Soup), dedicado ao domínio público pela licença **CC0 1.0** (`LICENSE.txt` nesta pasta).
Atribuição não é obrigatória, mas os autores pedem o crédito como cortesia.

- Origem: https://opengameart.org/content/dungeon-crawl-32x32-tiles (arquivo `Dungeon Crawl Stone Soup Full.zip`)
- Também em: https://github.com/crawl/tiles
- Artistas (lista do README do pack): Eino Keskitalo, David Lawrence Ramsey, Enne Walker, Poor_Yurik,
  Stefan O'Rear, Jude Brown, Ixtli, Robert Vollmert, abrahamwl, dshaligram, Jesse Luehrs, David Ploog,
  Mitsuhiro Itakura, coolio, Denzi e demais colaboradores do Dungeon Crawl.

própria do Kusa, gerada no código (`apps/client/src/art`).
