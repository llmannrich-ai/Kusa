# Folha C — prompts para colar no ChatGPT (Pântano do Kosaradius)

Um prompt por inimigo. Para cada um:

1. Abra uma conversa no ChatGPT (de preferência a mesma em que a folha B do inimigo foi feita).
2. Anexe as imagens indicadas em **Anexar** (ficam em `docs/arte/pantano-do-kosaradius/`).
3. Cole o prompt e gere.
4. Salve a imagem com o nome indicado em **Salvar como** e mande para o Claude (2 ou mais por mensagem).

Se a imagem vier com pose muito aberta (arma esticada para longe do corpo) ou com efeitos desenhados (poeira, névoa, pedra voando), gere de novo: o jogo desenha os efeitos e pose larga pesa na memória do celular.

Ordem sugerida: 1 → 8.
